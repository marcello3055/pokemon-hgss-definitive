# Pokémon HeartGold Definitive Edition
Projeto pessoal de modificação de HeartGold US. Não é afiliado à Nintendo, Game Freak ou pret.

Este repositório contém apenas alterações próprias, scripts e documentação.
A base é recuperada pelo commit de upstream.lock.json em uma pasta ignorada.
Não contém ROM, assets, SDK, compilador, BIOS ou save comercial.

**Não há versão 1.0 pronta.** TMs infinitas estão em WIP; leia PROGRESS.md.
Nuzlocke expressamente excluído.

- PROGRESS.md: estado vigente e próximo passo.
- docs/BUILD.md: reconstrução pelo agente.
- docs/TESTS.md: evidências, limitações e testes pendentes.
- AGENTS.md: regras de retomada, checkpoint e publicação.
- scripts/checkpoint.py: auditoria, bundle, restauração de teste e ZIP.
